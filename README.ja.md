# EMA Strategy Validation

**EMAを使ったトレンド押し目手法2つ・407トレードのバックテストの統計的検証（FX・ゴールド、2023〜2025年）**

[English README](README.md)

20EMAと200EMAを軸にした裁量トレード手法を2つ設計し、Forex Testerで手動バックテストしました（12テスト・6銘柄・2023〜2025年）。
このリポジトリでは、全トレードをPythonで独立に再集計し、次の3点を検証しています。

- 優位性は本物か
- コスト控除後にどれくらい残るか
- どの程度のドローダウンを想定すべきか

**要約**

- **407トレードで、手数料控除後の期待値は1トレードあたり +0.41R**（95%ブートストラップ信頼区間 +0.28R〜+0.55R）。ブートストラップで期待値が0以下になる確率は0.1%未満です（ただしバックテスト自体に偏りがないことが前提です。[限界](#限界)を参照）。
- **どちらの手法も単独で優位性があります**（200EMA +0.39R、20EMA +0.42R）。ただし**両者の間に有意差はありません**（並べ替え検定 p = 0.86）。どちらを選ぶかは、優位性ではなく相性と頻度で決まります。
- 1トレード1%リスクで今後100トレードをシミュレーションすると、最大ドローダウンは**中央値で約6R**（95パーセンタイルで約11R）、**連敗は最大8回**程度を想定しておく必要があります。
- 損益の形は**トレンドフォロー型**です。勝率は約55%、平均利益は平均損失の約1.6倍で、損益分岐の勝率は39%です。−1Rを超える損失は1件もありません（負け185件のうち183件がちょうどSL、2件は早期撤退）。

## 手法の概要

どちらの手法も、上位足2本で確認したトレンド方向にだけ入ります。押し目（戻り）を待ち、値動きの構造が調整の終わりを示したところでエントリーします。

| | [200EMA手法](docs/strategy-200ema.md)（[日本語原文](docs/ja/strategy-200ema.ja.md)） | [20EMA手法](docs/strategy-20ema.md)（[日本語原文](docs/ja/strategy-20ema.ja.md)） |
|---|---|---|
| 狙い | 深い押し目の後のトレンド継続 | 旧トレンドの構造が崩れた後の最初の推進（第3波） |
| フィルター | 上位足の200EMAがエントリー方向に傾いている | 同じ |
| セットアップ | EMAクロス → **200EMA**までの押し目 | 第一波が旧構造を否定 → **20EMA**までの押し目 |
| トリガー | 調整波の切り下げ/切り上げラインを実体でブレイク（反応のあるスイングを結べる場合のみ） | 20EMAにタッチした足の高安値を実体でブレイク |
| 利確 | 直前の推進波のN計算値 | 崩れた旧トレンドが残した未到達の高安値 |
| 執行足 | 5分足（1hも） | 5分足（1hも） |

**Hybrid** は、EURUSDで両方のセットアップを併用したテストです。

手法のページでは、ルールを考え方のレベルで説明しています。各セットアップを採点する詳細な評価基準は非公開です。

## 結果

数値はすべて **R**（各トレードで取ったリスクに対する倍数）、**手数料控除後**です。定義は [methodology](docs/methodology.md) を参照してください。

| 戦略 | トレード数 | 勝率 | 平均利益/平均損失 | 期待値（net） | 95% 信頼区間 | P(E≤0) | 最大DD（R） |
|---|---:|---:|---:|---:|---:|---:|---:|
| 200EMA | 183 | 54.1% | 1.55 | **+0.39** | +0.19 〜 +0.59 | <0.001 | 7.3 |
| 20EMA | 141 | 55.3% | 1.53 | **+0.42** | +0.19 〜 +0.64 | <0.001 | 6.4 |
| Hybrid | 83 | 54.2% | 1.63 | **+0.46** | +0.15 〜 +0.78 | 0.002 | 6.3 |
| **全体** | **407** | **54.5%** | **1.56** | **+0.41** | **+0.28 〜 +0.55** | **<0.001** | 6.2 |

## わかったこと

1. **全テストを合算すると優位性は統計的に明確ですが、テスト単体では判断できません。** 信頼区間が単独で0を上回るのは12テスト中5つだけです。多くのテストは20〜60トレードで、勝率55%の手法を評価するには少なすぎます。Rに揃えて合算することで、初めて結論が出せます。
2. **初期の結果は良すぎました。** 初期の小さなテストは +0.76R〜+1.09R でしたが、36トレード以上の大きなテストでは +0.2R〜+0.45R に落ち着いています。現実的な見積もりは後者と考えています。
3. **5分足のFXでは手数料が効きます。** 5分足のFXテストでは手数料が1トレードあたり0.08〜0.10Rかかり、粗利の15〜30%を占めます（例：AUDUSD-20EMA は +0.32R → +0.22R）。手数料がほぼゼロのゴールドでは、粗利がそのまま残ります。
4. **20EMA手法はロングがショートを大きく上回ります。** ロングは +0.65R（信頼区間 +0.35〜+0.95）ですが、ショートは +0.13R で、信頼区間が0をまたいでいます。テストした3銘柄（AUDUSD・GBPUSD・XAUUSD）のすべてでロングがショートを上回りました。200EMA手法はロング・ショートとも期待値がプラスです。20EMAのショートに追加のフィルターが必要かどうかが、フォワードテストで最初に確かめるべき点です。
5. **負けトレードの振り返りがルール改訂につながりました。** 振り返りで、200EMA手法の負けは、レンジ相場（200EMAが横ばい）でクロスに従って入った局面に集中していることがわかりました。データ上も、200EMAテストで唯一マイナスだった四半期は2024年Q2（18トレードで −2.7R）です。ここから上位足の傾きフィルターが生まれました。詳細は [research log](docs/research-log.md) を参照してください。

## 限界

これはライブトレードではなく、手動・裁量のバックテストです。主な注意点は次のとおりです。

- **後知恵と裁量のバイアス。** 相場の大まかな流れを知っていることが、判断に影響しうる。
- **アウトオブサンプルではない。** テストを進めながらルールを改訂している。
- **スリッページは考慮していない。** 手数料とスプレッドは含んでいる。
- **トレード同士を独立とみなしている。** リサンプリングの前提であり、相場局面の変化はこれに反するため、裾のドローダウンは過小評価の可能性がある。

詳細は [methodology § Limitations](docs/methodology.md#6-limitations) を参照してください。

## 今後の予定

1. **機械的なベースラインとの比較。** 同じ決済ルールでランダムにエントリーした場合より優れているか、上位足の傾きフィルター単体に効果があるか、機械化した版と比べて裁量の選別がどれだけ上乗せしているかを検証します（[設計](docs/roadmap.md)）。
2. **フォワードテスト。** ルールを固定してデモ口座で運用し、このパイプラインで真のアウトオブサンプルとして分析します。

## 再現方法

```bash
make setup     # .venv を作成し、バージョン固定の依存パッケージをインストール
make lint      # ruff による静的解析・フォーマット確認
make test      # 24件のテスト（Forex Tester のレポートとの数値突き合わせを含む）
make report    # reports/ の要約・表・図をすべて再生成
```
