# 20EMA手法

### 20EMA手法 (改訂版)

### エントリー条件

1. 20EMAと200EMAのクロスを確認
2. **左側にトレンド転換を確認できる波動が存在する**
    - 反対方向のトレンドが崩れたことを示す高安値構造があること
3. **そこから第一波が完成している**
    - 第一波の高値/安値が形成されていること
    - その高安値が更新されないまま価格が戻ってきていること
4. 調整波として20EMAへのタッチを確認
5. タッチした足の最高安値を実体で抜けたらエントリー

### 利確

**左側のトレンド転換を確認した波動の中**の押し安値/戻り高値から選ぶ

### 損切り

押し安値/戻り高値（既存ルール通り）

### 見送り条件

- 第一波が観測できない / 完成していない
- 左側にトレンド転換を確認できる波動構造がない
- 利確基準となる高安値が「トレンド転換波動内」に見られない
- タッチ後の次の足で最高安値をブレイクした場合
- 上位足、執行足のトレンド方向不一致。
